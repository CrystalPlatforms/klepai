## Notes

- Quit confirmation alert (agents running) applies to **every quit path on all platforms**: macOS Cmd+Q / Quit Klepai, Windows/Linux window close (X) and ☰ → Quit.
- Details items **reveal and focus** the matching field in the DetailPane (navigation, not duplicated controls).
- Settings items **deep-link** into the Settings dialog section; Import skill also opens the file picker directly.
- Shortcuts: Cmd+N (new conversation), Cmd+E (export), Cmd+F (search conversations), Cmd+B (toggle sidebar), Cmd+R (rename conversation), Cmd+, (Settings) + standard system roles.
- No on/off switch in Settings — menus are always on. Labels in English.
- Single-window app in v1.1.0 ("New window" dropped — possible future version).
- Windows/Linux: ☰ in the Sidebar header, one dropdown mirroring the macOS sections plus About / Check for Updates / Quit (no app menu there).
